# 📈 Pronóstico de Ganancias y Análisis de Rentabilidad de Productos

## 📝 Descripción del Proyecto
Este proyecto presenta un análisis integral de rendimiento comercial, integrando datos históricos de ventas con modelos predictivos de inteligencia de negocios. El análisis identifica no solo qué se vendió, sino qué productos generan el mayor impacto en el margen de beneficio y cómo se comportarán las ganancias en los próximos años (2025-2026).

---

## 🚀 Habilidades Técnicas Demostradas
* **Modelado Predictivo (Forecasting):** Aplicación de algoritmos de suavizado exponencial para proyectar ganancias futuras con intervalos de confianza del 95%.
* **Análisis de Rentabilidad:** Clasificación de productos basada en el **Profit (Beneficio)** neto, diferenciándolo del volumen de ventas bruto.
* **Agregación Temporal:** Transformación de datos transaccionales diarios en métricas trimestrales para identificar tendencias estacionales.
* **Limpieza de Datos:** Procesamiento de categorías (Office, Accessories, Electronics) y regiones para asegurar la integridad del análisis.

---

## 🔍 Hallazgos Principales (Insights)

### 1. Los "Profit Drivers" (Productos más rentables)
A pesar de la variedad del catálogo, la rentabilidad está concentrada en tecnología:
* **Líder de Ganancias:** Las **Cámaras** generan el mayor beneficio acumulado.
* **Top 5:** Camera, Monitor, Mouse, Laptop y Printer representan el núcleo del margen operativo.

## 📂 Estructura del Libro de Excel
El archivo `.xlsx` está organizado en las siguientes hojas:
1. **Datos:** Registro transaccional completo (Fechas, Productos, Región, Cantidad, Ventas y Ganancia).
2. **Productos más rentables:** Tabla dinámica que prioriza el beneficio neto por categoría de producto.
3. **Ganancias Trimestrales:** Resumen ejecutivo de la evolución financiera por años y trimestres.
4. **Pronóstico 2025 y 2026:** Hoja de previsión con datos proyectados y márgenes de error estadístico.
